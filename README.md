# Ram Namburi portfolio site

A static site: `index.html` plus `Ram_Namburi_Resume.pdf`. No build step.

## Host it on GitHub Pages (free)

1. Sign in to GitHub as `ramnamburi1415`.
2. Create a new public repository named exactly `ramnamburi1415.github.io`.
3. On the repository page choose "uploading an existing file", then drag in `index.html` and `Ram_Namburi_Resume.pdf`. Commit.
4. Wait about a minute, then open https://ramnamburi1415.github.io

If the page does not appear, open Settings > Pages and set Source to "Deploy from a branch", branch `main`, folder `/ (root)`.

## Update it

- Text: edit `index.html` on GitHub (pencil icon) and commit.
- Resume: upload a new PDF with the same file name, `Ram_Namburi_Resume.pdf`.

## Custom domain (optional)

Buy a domain, then add it under Settings > Pages > Custom domain and follow the DNS instructions GitHub shows.
